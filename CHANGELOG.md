# Contributing

Thanks for your interest in improving Simple Counter.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test your changes locally.
5. Open a pull request with a clear description.

## Coding Guidelines

- Keep the project simple and easy to understand.
- Prefer readable Python code over clever abstractions.
- Match the existing style and layout where possible.
- Document user-facing changes in the README when relevant.

## Reporting Bugs

Please include:

- Your operating system
- Python version
- Steps to reproduce
- Expected behavior
- Actual behavior

## Feature Requests

Open an issue describing the problem you want to solve and why it would be useful.

## Pull Request Checklist

- Code runs locally
- Documentation updated if needed
- No unrelated changes included
- Clear commit history or tidy diff
